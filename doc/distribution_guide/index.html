AWS Conn Tray 配布ガイド

このドキュメントは、インストーラ/アンインストーラを含めた配布パッケージに同梱する想定の詳細手順です。GUI/Tk ウィザードを前提にしていますが、CLI も同等の機能を提供します。

1. 同梱ファイルの例

  • installer_ui.py / installer.py（インストーラ: GUI/CLI）
  • uninstaller_ui.py / uninstaller.py（アンインストーラ: GUI/CLI）
  • run_installer_windows.bat / run_installer_macos.command / run_installer_linux.sh（ダブルクリック起動用ラッパー）
  • run_uninstaller_windows.bat / run_uninstaller_macos.command / run_uninstaller_linux.sh
  • tray_app.py（本体エントリポイント）
  • autostart_gui.py（自動起動トグル GUI/CLI）
  • aws_conn_tray/（本体ライブラリ一式）
  • config/config.example.json（設定サンプル）
  • requirements.txt / requirements-dev.txt（依存定義）
  • doc/（本ドキュメントや各種仕様/テンプレート）

2. 前提条件

  • OS: Linux (systemd 想定) / Windows 10+ / macOS 12+
  • Python 3.10+ が利用可能であること（インストーラがインストール先に venv を作成）
  • AWS CLI v2 / Session Manager Plugin が導入済み
  • aws configure sso を完了済み（GUI から既存プロファイルの読込・新規追加も可）
  • tkinter が利用可能（Linux では python3-tk を追加パッケージで導入）
インストーラは前提チェックを自動で行い、不足がある場合は推奨コマンドを表示します（プレビュー時は表示のみ）。

3. インストール手順

3-0. ダブルクリックで起動する場合

  • Windows: run_installer_windows.bat をダブルクリック。同梱の Python / .venv を優先し、見つからない場合は GUI ダイアログで確認のうえ winget install -e --id Python.Python を実行します（UAC で管理者権限が求められる場合があります）。
  • macOS: run_installer_macos.command をダブルクリック（必要なら chmod +x）。同梱や python3 が無い場合はダイアログで確認のうえ brew install python を実行します。
  • Linux: run_installer_linux.sh を実行（必要なら chmod +x）。Python が無い場合は GUI (zenity/kdialog) もしくはプロンプトで確認のうえ apt-get/dnf/zypper で python3 を導入します（sudo が必要）。

3-1. GUI インストーラ（推奨）

  1. ターミナルで配布フォルダに移動し、python installer_ui.py を実行。
  2. 「前提チェック」で不足がなければ「次へ」。不足があれば推奨コマンドを確認し整備。
  3. インストール先とショートカット先を確認（任意で変更）。
  4. 「確認」で内容を確認し「インストール」を押下。
  5. 進捗バーが完了したら「完了」を押下して終了。

実行される処理の概要:

  • インストール先に .venv を作成し、pip install -r requirements.txt
  • 最低限のファイルのみコピー（テスト・ドキュメントを除外）
  • 自動起動エントリとショートカットを OS ごとに生成（いずれも .venv の Python と tray_app.py を呼び出す）
  • インストールメタデータを保存（アンインストールで使用）

3-2. CLI インストーラ

python installer.py --install-dir ~/aws-conn-tray
# プレビューのみ（書き込みなし）
python installer.py --install-dir ~/aws-conn-tray --preview

4. アンインストール手順

4-1. GUI アンインストーラ

ダブルクリックで起動する場合:

  • Windows: run_uninstaller_windows.bat（Python 未導入時は GUI で確認のうえ winget で導入可）
  • macOS: run_uninstaller_macos.command（Python 未導入時はダイアログ確認のうえ brew で導入可）
  • Linux: run_uninstaller_linux.sh（Python 未導入時は GUI/プロンプト確認のうえ apt/dnf/zypper で導入可）
  1. python uninstaller_ui.py を実行。
  2. メタデータが見つかる場合はパスがロックされ編集不可。見つからない場合はデフォルトパスを編集可。
  3. 「確認」で削除対象を確認し、「アンインストール」を押下。
  4. 自動起動解除 → ショートカット削除 → インストール先削除 → メタデータ削除を順に実行。

4-2. CLI アンインストーラ

python uninstaller.py --install-dir ~/aws-conn-tray
依存導入に失敗した場合はインストーラが自動でクリーンアップし、インストールを中断します。

5. 使い方（本体アプリ）

  • 通常起動: python tray_app.py（単一インスタンスロックで二重起動を防止）
  • 設定のみ開く: python tray_app.py --settings（本体は起動せず、起動中の場合のみ保存後に再起動）

トレイメニュー

  • ⚙️ 設定: タブ形式で config.json を編集。必須チェック・デフォルト/ペーストボタン付き。保存時は起動中なら自動再起動。
  • SSO ログイン: 認可 URL を取得し、Qt WebView（失敗時はブラウザ）でログイン。トークン失効時はミニダイアログと通知を表示。
  • 全フォワード再接続 / 個別再接続: SSM ポートフォワードを再起動。衝突時はリトライ＋通知。
  • 終了: アプリを終了。

自動起動トグル

  • ショートカット「AWS Conn Tray - 自動起動解除」または python autostart_gui.py を実行。
  • 現在の登録状態を表示し、「自動起動登録/解除」ボタンでトグル。状態表示は操作直後に更新。

6. リリースノート（抜粋）

  • インストーラ刷新: Tk ウィザードで前提チェック → venv 作成 → 依存導入 → 自動起動生成まで一括実行。プレビューモード対応。
  • 設定専用起動: tray_app.py --settings で本体を起動せず設定のみ編集。起動中の場合のみ保存後に再起動。
  • 自動起動 GUI: 登録状態の可視化とワンクリックトグルを追加。各 OS で .venv の Python を使うエントリを生成。
  • 単一インスタンスロック: fasteners（フォールバックあり）で二重起動を防止。
  • SSO/設定 UX 強化: 既存プロファイルのプルダウン読込、新規追加、必須チェック、デフォルト/ペーストボタンを実装。ログイン結果でウィザードの遷移可否を制御。

7. トラブルシュート

  • tkinter が無くインストーラが起動しない: Linux は sudo apt-get install -y python3-tk を実行。
  • Qt WebView が開かない/落ちる: 通知やミニダイアログの「開く」からブラウザでログインする。
  • 二重起動メッセージが出る: 既存プロセスを終了してから再起動。
  • 依存導入で失敗: ログを確認し、再インストール。失敗時は自動クリーンアップされます。
