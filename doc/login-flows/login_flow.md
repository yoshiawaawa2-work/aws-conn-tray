# SSO ログインの流れ（wx 版・利用者向け）

Linux / Windows / macOS で動作する wx 版のフローです。  
「いつ何が起き、ユーザーは何をすればいいか」を中心にまとめています。

---

## 1. トークンが無効になったとき
- 右下に小さなダイアログ（MiniPrompt）が出て「SSO トークンが無効です」と表示されます。
- ボタン「開く」を押すと、認証画面（WebView）が背面・非アクティブで起動します。
- WebView が開けない／クラッシュした場合は、MiniPrompt と通知に「開く」が出るので、それを押すとデフォルトブラウザで認証画面が開きます。

## 2. メニューの「SSO ログイン」を選んだとき
- 通知が出ます（「認証画面を開きます（フォーカスは奪いません）」）。
- 認証画面（WebView）が背面・非アクティブで開きます。
- うまく開かなかった場合は、右下のダイアログと通知の「開く」からブラウザを開いてください。

## 3. 自動再ログイン（トークン期限が近づいたとき）
- アプリが認可 URL を取得すると、自動で認証画面（WebView）を起動します（フォーカスは奪いません）。
- WebView が起動できなかった場合は、右下ダイアログと通知に「開く」が出るので、そこからブラウザでログインしてください。
- 認可 URL が取得できなかった場合は、ブラウザで start URL を開くよう案内します。

---

## 認証画面の表示～完了まで（共通の流れ）

```text
[開くを押す（または自動起動）]
         │
         v
    WebView 起動 (非アクティブ/背面)
         │
         ├─ 表示成功 → 認証ページでログイン
         │                  │
         │                  ├─ 127.0.0.1/.../callback を検出
         │                  │      ├─ WebView 自動クローズ
         │                  │      └─ 通知「SSO ログイン完了」
         │                  │
         │                  └─ 画面を閉じれば終了
         │
         └─ 起動失敗 / クラッシュ
                ├─ 右下ダイアログに「開く」再表示
                └─ 通知「WebView を開けませんでした」
                        └─ 「開く」でデフォルトブラウザを起動
```

※ ブラウザフォールバックでもフローは同じで、認証完了すれば WebView は関与せずブラウザ側だけで終了します。  
※ ブラウザフォールバック時は、一定時間経過後に aws sso login のサブプロセスが自動キャンセルされます（ログイン完了済みならキャンセルしません）。

---

## よくある確認ポイント
- 認証画面が見つからない: 背面で開くのでタスクバーを確認。見つからなければ MiniPrompt/通知の「開く」でブラウザを開く。
- すぐ閉じる: 認証が完了した場合は自動で閉じます。通知「SSO ログイン完了」が出ていれば成功です。
- 繰り返し失敗する: MiniPrompt に「再試行」が出たら押して再取得。ブラウザでのフォールバックも利用してください。
